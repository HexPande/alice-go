# alice-go

Основа для собственного навыка Яндекс Алисы на Go. Начните с простого диалога и добавляйте свои сценарии.

[Релизы](https://github.com/HexPande/alice-go/releases) · [Ошибки и предложения](https://github.com/HexPande/alice-go/issues)

## Возможности

- Подключение к Яндекс Диалогам.
- Ответы на вопросы через OpenAI API.
- Настройка модели и поведения помощника через админку.

## Настройка помощника

После запуска откройте `http://<адрес-сервера>:<порт>/_/` и войдите как администратор.

1. Откройте коллекцию **assistant_settings**, запись **default**.
2. Вставьте ключ OpenAI API в **api_key** и выберите модель в **model**.
3. При необходимости отредактируйте **system_prompt** — базовую инструкцию для помощника. Начальный вариант уже заполнен.
4. Включите **enabled** и сохраните изменения.

Здесь же можно изменить приветствие, сообщение при ошибке, время ожидания и длину генерации. Настройки применяются без перезапуска.

Для работы нужен отдельный ключ и доступный баланс OpenAI API; подписка ChatGPT не заменяет оплату API. Вопросы передаются в OpenAI для формирования ответа. В этой версии каждый вопрос обрабатывается отдельно, без истории предыдущих реплик.

## Системные требования

- **ОС:** Debian, Ubuntu или Raspberry Pi OS с systemd.
- Доступ к интернету и права администратора (`sudo` или root).

Установщик проверит совместимость системы и наличие подходящей сборки. Установка Go не требуется.

## Установка

Установите `curl` и корневые сертификаты:

```sh
sudo apt update
sudo apt install -y curl ca-certificates
```

Запустите установщик и следуйте подсказкам:

```sh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/HexPande/alice-go/main/install.sh)"
```

## Обновление

Повторно запустите установщик:

```sh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/HexPande/alice-go/main/install.sh)"
```

## Подключение к Алисе

1. Настройте публичный HTTPS-адрес приложения через nginx или другой reverse proxy.
2. Создайте навык в [консоли Яндекс Диалогов](https://dialogs.yandex.ru/developer/).
3. Укажите адрес обработчика: `https://ваш-домен/alice`.
4. Проверьте диалог на вкладке тестирования.
