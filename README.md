# alice-go

Основа для собственного навыка Яндекс Алисы на Go и [PocketBase](https://pocketbase.io/). Разворачивается на Raspberry Pi и позволяет начать с простого диалога, постепенно добавляя свои сценарии.

[Релизы](https://github.com/HexPande/alice-go/releases) · [Обсуждение ошибок и предложений](https://github.com/HexPande/alice-go/issues)

## Возможности

- Подключение к Яндекс Диалогам.
- Базовые сценарии: приветствие, помощь и завершение разговора.
- Встроенная панель управления PocketBase.
- Установка и обновление одной командой.
- Резервное копирование данных перед обновлением.

## Установка на Raspberry Pi

Поддерживаются Raspberry Pi 2, 3, 4 и 5 с Debian: 64-битная ОС или 32-битная на ARMv7+. Для установки нужен доступ к интернету и права `sudo`.

Подготовьте систему один раз:

```sh
sudo apt update
sudo apt install -y ca-certificates curl bash util-linux
```

Установите последний стабильный релиз:

```sh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/HexPande/alice-go/main/install.sh)"
```

Установщик подберёт сборку для вашего устройства и настроит автоматический запуск. Go и токен GitHub не требуются.

## Обновление

Повторите команду установки:

```sh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/HexPande/alice-go/main/install.sh)"
```

Перед заменой приложения установщик сохранит резервную копию данных и предыдущей версии.

## Подключение к Алисе

1. Настройте публичный HTTPS-адрес приложения через nginx или другой reverse proxy.
2. Создайте навык в [консоли Яндекс Диалогов](https://dialogs.yandex.ru/developer/).
3. Укажите адрес обработчика: `https://ваш-домен/alice`.
4. Проверьте диалог на вкладке тестирования.

После установки приложение доступно на Raspberry Pi по адресу `http://127.0.0.1:8090`. Используйте его как адрес назначения для reverse proxy на том же устройстве.

## Панель управления

Для доступа с компьютера откройте SSH-туннель, указав своего пользователя и адрес Raspberry Pi:

```sh
ssh -N -L 8090:127.0.0.1:8090 pi@raspberrypi.local
```

Откройте [панель управления](http://127.0.0.1:8090/_/) в браузере. Ссылка для создания первого администратора доступна в журнале приложения:

```sh
sudo journalctl -u alice-go -n 100 --no-pager
```
